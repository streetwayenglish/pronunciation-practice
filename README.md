# Emma Speak

An English pronunciation and conversation practice app. Record yourself, get real pronunciation scoring, and practice live conversation with an AI avatar tutor — in the browser today, and soon as native iOS and Android apps.

## Highlights

- **Pronunciation drills** — read a sentence, record yourself, get word-by-word scoring and feedback.
- **Live AI tutors** — real-time voice conversation with an avatar tutor, with pronunciation feedback per turn.
- **Multiple tracks** — Conversation, Business English, Travel English, Job Interview, and more.
- **iOS & Android** — the same experience, wrapped as native apps via Capacitor.

## Tech at a glance

Plain HTML/CSS/JS frontend (no build step), backed by a Cloudflare Worker for speech-to-text, pronunciation scoring, and AI chat.

## Running it locally

```bash
npx serve .
```

Then open `http://localhost:3000` (or `index.html` directly).
